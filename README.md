# INTERNET-PROGRAMMING - Welcome Website

Welcome to the premium styled website built for Internet Programming. This project features a responsive CSS Grid layout, elegant Cambria typography, custom interactive blue buttons, and a seamless pure CSS scrolling update ticker.

## 🛠️ Features
- **Responsive CSS Grid Layout**: Clean two-column card structure aligning elements precisely.
- **Glassmorphism Panels**: Semi-transparent background panels with blur filters and light shadows.
- **Typography & Font**: Configured with Cambria serif typography and an explicit 14px size scale.
- **Interactive Blue Buttons**: Customized active and hover states with smooth micro-animations.
- **CSS Marquee Scroller**: High-performance scrolling track created with pure CSS keyframes.

## ⚙️ How to Enable GitHub Pages (if not already active)
If clicking the link above displays a 404 page, follow these simple steps to enable it:
1. Go to your repository page: [https://github.com/Karthik0528/INTERNET-PROGRAMMING](https://github.com/Karthik0528/INTERNET-PROGRAMMING)
2. Click on the **Settings** tab at the top.
3. On the left sidebar, click on **Pages**.
4. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
5. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
6. Wait 1–2 minutes, and the website will be live at the link above!
